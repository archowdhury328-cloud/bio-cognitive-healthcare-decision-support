| | |
|---|---|
| Source | PhysioNet, https://physionet.org/content/mimic-iv-demo/2.2/ |
| DOI | 10.13026/07hj-2a80 |
| Contents | 100 de-identified patients (140 ICU stays); no free-text notes |

Acquire: `python -m biocog fetch-data` (downloads the zip, verifies each file, extracts to `data/raw/mimic-iv-demo-2.2/`). Verify later with `python -m biocog verify-data --which mimic`. Manual route: download the zip from the PhysioNet page, unzip so that `hosp/` and `icu/` sit directly under `data/raw/mimic-iv-demo-2.2/`, then verify.

Please cite: Johnson A, Bulgarelli L, Pollard T, Gow B, Moody B, Horng S, Celi LA, Mark R. *MIMIC-IV Clinical Database Demo* (version 2.2), PhysioNet, doi:10.13026/07hj-2a80; Johnson AEW et al., *MIMIC-IV, a freely accessible electronic health record dataset*, Sci Data 10, 1 (2023); Goldberger AL et al., *PhysioBank, PhysioToolkit, and PhysioNet*, Circulation 101(23):e215-e220 (2000).

### Tables used and how they are joined

| table | use | join key |
|---|---|---|
| `icu/icustays` | stay, ICU in/out time | `stay_id` |
| `hosp/patients` | sex, `anchor_age`, `anchor_year` (age = anchor_age + year(intime) - anchor_year) | `subject_id` |
| `hosp/admissions` | admission type (emergency flag) | `hadm_id` |
| `icu/chartevents` | HR 220045; SBP 220179 and 220050; RR 220210; SpO2 220277; temperature 223762 (degC) and 223761 (degF converted) | `stay_id` |
| `hosp/labevents` | glucose **50931 only**; creatinine 50912; sodium 50983; potassium 50971; WBC 51301; BUN 51006 | `hadm_id` (rows without `hadm_id` are excluded) |

Availability timestamps: labs `availtime = storetime`; chart events `availtime = max(charttime, storetime)` because MIMIC sometimes stores a chart value before its chart time. Blood-gas glucose (50809, 52027) is deliberately **not** mixed with chemistry glucose. Lab rows whose unit string differs from the expected one are dropped (zero in the demo). Out-of-range values are dropped (60 chart rows). No patient is ever matched across datasets.

### Missingness and survival through the filters

Machine-generated, with exact counts for the run that produced the published results: `results/mimic_demo/results.md` (cohort flow) and `results/mimic_demo/run_manifest.json` (adapter report). Qualitatively: every ICU stay has some vitals and some labs, but glucose is measured irregularly, so most hourly windows have no glucose in the following six hours and are labelled **unknown**, not negative. Many stays are excluded because a qualifying glucose was already recorded at or before the first landmark (including in the hours before ICU admission within the same admission).

### What this demo can and cannot show

It can show that ingestion, cohort rules, availability handling and scoring run on real hospital data. It **cannot** establish the paper's claimed chronic-disease performance, and with roughly 20 independent event patients (a handful in the test split) it cannot support a performance claim of any kind. Confidence intervals are withheld when positive patients are too few, and metrics are reported `n/a` rather than as numbers when a denominator is too small.

### Selective testing

Glucose is measured when clinicians choose to measure it. A window is labelled negative only if a glucose **was** measured inside it and was <= 180; windows with no measurement are unknown. Therefore predictions describe tested windows and say nothing about untested time, and the event is "excursion recorded", which depends on being tested at all.

## 3. Offline synthetic example

`data/fixture/` is generated by `src/biocog/synth.py` (seed 7, 120 patients). It is **entirely synthetic**: no real person, site or measurement. It exists so tests and the demo run offline. All synthetic figures and result files are labelled SYNTHETIC.

## 4. What is and is not published

Published: code, the synthetic fixture, checksum manifest, aggregate measurements, synthetic examples. **Not published** (git-ignored, local only): raw MIMIC files (`data/raw/`), patient-level predictions and trajectories from real data (`runs_local/`). No real patient trajectory appears in any figure.
